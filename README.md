# 『AI 목회자 바이브 코딩』 예제 모음

『AI 목회자 바이브 코딩』(쟈니파커 지음)의 장별 예제 파일입니다.
코드를 몰라도 됩니다. 내려받아 **Cursor로 폴더를 열고, 말로 시키시면** 됩니다.

만든 곳: **뉴엠미션 (newMmission)**

---

## 내려받는 법

1. 이 페이지 위쪽의 초록색 **Code** 단추를 누릅니다.
2. **Download ZIP**을 누릅니다.
3. 내려받은 파일을 **바탕화면에 압축 풀기** 합니다.
4. 필요한 장의 폴더를 **Cursor**로 엽니다. (Cursor 왼쪽 위 **File → Open Folder**)

git을 아시는 분은 이렇게 받으셔도 됩니다.

```
git clone https://github.com/newMmission/ai-pastor-vibe-coding.git
```

## 장별 폴더

| 폴더 | 책의 장 | 내용 |
|---|---|---|
| `11장_설교서랍/` | 11장. 설교 — 제목·본문·구성, 원고 마감까지 AI가 돕는다 | 메모 → 주제 → 마인드맵·개요 → 설교본 → @@ 고치기 → 완성본. 설교 구성은 "사고의 설계"(본론 먼저 · TREE · 전이 문장) |

(다른 장의 예제는 차례로 더해집니다.)

### 11장 설교서랍 — 처음 쓰는 법

1. **파이썬**을 설치합니다 (책 11장 "파이썬 설치하기"). 설치 화면에서 **Add python.exe to PATH**에 꼭 체크하십시오.
2. 압축을 푼 `11장_설교서랍` 폴더에서 **`설치.bat`**을 두 번 누릅니다. → 바탕화면에 **[설교서랍]** 아이콘이 생깁니다.
3. 아이콘을 두 번 누르면 설교서랍 화면이 인터넷 창에 열립니다.
4. 화면의 **[Cursor로 열기]**를 누르고, Cursor 대화창에 "메모 정리해 줘요"처럼 말합니다.

설교 글은 Cursor 안의 AI가 `설교서랍.md`(방법서)대로 씁니다. 화면은 저장하고, 보여 주고, 장절을 확인할 뿐입니다.

## 꼭 지켜 주십시오

- **성령의 일은 기계가 대신하지 않습니다.** AI가 낸 주제·초안·설교문은 재료일 뿐입니다. 본문을 정하고, 고르고, 완성본으로 정하는 것은 목사님이 하십니다.
- 메모와 예제에 **성도의 실명과 연락처를 넣지 마십시오.**
- AI가 낸 성경 구절과 인용은 **반드시 성경을 펴서 대조**하십시오.
- 비밀 열쇠(API 키 같은 것)를 담은 `.env` 파일은 이 저장소에 올리지 않습니다.
